Every time there is a technological breakthrough, humans are better off. With
each year we cure more diseases and we create devices and sofware that automate
stuff for us. That allws us to move forward and focus on more improvement in
areas that are more important to us.

Humans have to get really good at using new technology when it arrives and
humans need to make ure it suits the environment, if they want to harness it.

What humans cannot automate is their learning. Sure we learn every day as long
as we challenge ourselves but to aquire a skill: Taking a new concept, motor
movement, cognitive skill and making it a part of us. This takes effort fr
humans and there is a lot of administration around such a thing. 

We need to make sure we upate the catalog each time we master a topic, we have
to make sure the catalog is up to date, we have to make sure it is relevant
yadi yadi yada.

Humans must suffer if they want to learn, they have to make mistakes and feel a
reward after doin something hard. Most of the time we dont have any reward so
that is an additioal administrative task that adds on top of all the rest.

Machines now use the same method when learning. They get punished when they
make a mistake ad get rewarded when they do things correctly. This is just
throuh digital points so it is much easier to administrate. Humans dont give a
shit about points on a screen. Some do, but most dont.
